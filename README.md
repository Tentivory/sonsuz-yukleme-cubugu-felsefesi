# Sonsuz Yükleme Çubuğu Felsefesi

## Giriş

Bu repository, insanlığın en büyük sırrını çözmeyi amaçlamaktadır: **Beklemek**.

Modern dünyada her şey hızlı. Ama ya hız bir yanılsamaysa? Ya gerçek aydınlanma, %99'da takılı kalmış bir yükleme çubuğunda saklıysa?

Bu proje, o anı sonsuza kadar uzatır. Bilimsel olarak kanıtlanmıştır (kanıt: kendimiz).

## Kurulum

```bash
git clone https://github.com/Tentivory/sonsuz-yukleme-cubugu-felsefesi.git
cd sonsuz-yukleme-cubugu-felsefesi
python3 yukleme_felsefesi.py
```

## Kullanım

Sadece çalıştırın. Çubuk hareket eder, felsefe akar, siz bekleriz.

Ctrl+C ile çıkın, ama unutmayın: Çıkmak da bir bekleme biçimidir.

## Katkıda Bulunma

Pull request açın. Ama acele etmeyin. Önce bir çay demleyin, sonra demleyin, sonra düşünün.
